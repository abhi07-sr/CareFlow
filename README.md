## Featured Projects

### CareFlow — Clinical Pathway Process Mining
[![CareFlow stars](https://img.shields.io/github/stars/abhi07-sr/CareFlow?style=social)](https://github.com/abhi07-sr/CareFlow)  
Clinical pathway process-mining pipeline that ingests raw timestamped EHR event logs, reconstructs real patient flows, and surfaces hidden loops and bottlenecks (e.g., a paperwork loop sending 40% of patients back to triage). Includes BigQuery storage, dbt transforms, PM4Py discovery, and a dashboard for administrators.

Repository: https://github.com/abhi07-sr/CareFlow

---

### EHR-Cleaner — Event Log Normalization (example)
[![EHR-Cleaner](https://img.shields.io/badge/repo-EHR--Cleaner-blue?style=flat)](https://github.com/abhi07-sr/EHR-Cleaner)  
Data-cleaning utilities and dbt models to standardize EHR event logs into (case_id, activity_name, timestamp) for downstream process mining and analytics.

Repository: https://github.com/abhi07-sr/EHR-Cleaner
